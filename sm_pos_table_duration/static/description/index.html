Restaurant Table Seated Time

See how long every table has been seated, directly on the POS restaurant floor plan. A live timer appears on each occupied table so your staff can spot who has been waiting too long at a glance.
Key Features

Live Timer Per Table

Every occupied table shows the elapsed seated time (HH:MM:SS), refreshed every second.

From The First Order

Time is counted from the first open order on the table, so it reflects the real seating duration.

Zero Configuration

Install and it works. No settings, no fields to fill, works on every floor and every table shape.

How To Use

  • Install the module (requires the POS Restaurant module)
  • Open your restaurant POS and go to the floor plan
  • Occupied tables show a timer under the table number
  • The timer disappears when the table is paid and freed
